# Таро — личный справочник

Приложение не гадает: вы выбираете тему и выпавшие карты (прямые или перевёрнутые),
а оно показывает значение каждой карты в теме и то, как карты связаны между собой.
Значения и схемы раскладов опираются на «The Ultimate Guide to Tarot» Лиз Дин.

## Что умеет
- Вкладка «Вопрос»: пишете вопрос, тема определяется по словам, выбираете расклад — и сразу к картам
- Значения карт в 7 темах, связи между картами, схемы раскладов из книги
- Свои заметки к каждой карте (прямой и перевёрнутой) — видны прямо в раскладах
- Своя колода из своих картинок/фото (хранится в браузере, недостающие карты — из базовой колоды)
- Оформление: ренессанс, картины из общественного достояния (Wikimedia Commons)

## Сайт
https://t4nukimeat.github.io/tarot/ — веб-версия с готовыми колодами (без скачивания новых).

## Запуск на компьютере
- Меню приложений → **Таро**, или `python3 ~/tarot-app/server.py`
- Откроется http://127.0.0.1:8777 (Ctrl+C в терминале — остановить)
- `index.html` открывается и напрямую из файла, но тогда нельзя скачивать новые колоды

## Что где
- `data/` — значения карт (`cards-*.js`), связи (`meta.js`), схемы раскладов (`spreads.js`), каталог альбомов
- `js/interpret.js` — толкование связей, `js/app.js` — интерфейс
- `decks/<колода>/raw/` — картинки, `deck.json` — какая картинка какой карте
- `tools/deckimport.py` — скачивание колоды с rozamira-tarot.ru (`python3 tools/deckimport.py <ссылка на альбом>`)
- `tools/crawl_catalog.py` — обновить каталог альбомов: `python3 tools/crawl_catalog.py data/catalog.json`

## Проверки
`gjs -m tests/test.js` — проверяет все 78 карт, схемы и толкование всех пар карт.
